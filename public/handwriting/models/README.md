# IS-Net general-use cutout model

`isnet-general-use-q8.onnx` is the Apache-2.0 IS-Net general-use ONNX model,
quantized by SacredNoir for browser CPU inference. Source:
https://huggingface.co/SacredNoir/isnet-general-use-onnx

SHA-256: `feed6f32a5e707ca7e939576b2d891b23fb9eb4114749657a5efc64e8651e43a`

The model is downloaded to the browser; the user's photo is processed on the
device and is not sent to the model host.
